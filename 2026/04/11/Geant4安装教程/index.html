编译选项说明
-DCMAKE_INSTALL_PREFIX用于指定安装目录（Geant4 库、头文件和支持文件的安装目录）
-DGEANT4_INSTALL_DATA=ON表示在在编译 Geant4 时自动下载和安装外部数据库
-DGEANT4_USE_OPENGL_X11=ON表示编译X11 OpenGL可视化驱动程序
-DGEANT4_USE_RAYTRACER_X11=ON表示编译支持 X11 的 RayTracer可视化驱动程序
-DGEANT4_USE_QT=ON表示编译 Qt 用户界面和可视化驱动程序
-DGEANT4_BUILD_MULTITHREADED=ON表示编译支持多线程的 Geant4 库
-DGEANT4_USE_GDML=ON表示启用 GDML 几何文件读写支持，需要系统已安装 Xerces-C++ 头文件和库
-DGEANT4_INSTALL_DATADIR用于指定外部数据库目录

安装预编译包

官方 EXE 预编译包是否支持 GDML 取决于发布包编译时是否已经启用 GEANT4_USE_GDML。如果安装后需要稳定使用 GDML，推荐按后面的“源码编译”方式重新编译 Geant4，并在 CMake 中显式打开 GEANT4_USE_GDML=ON。

可视化源码编译

下载Geant4源码

换源安装qt5.12.2，勾选archive，勾选msvc2019-64bit编译器

安装cmake3.26.6，勾选添加到系统环境变量

安装visual studio2019，勾选C++桌面开发

解压datasets并配置环境变量

将下载好的datasets全部解压到安装目录的data文件夹下（C:\Program Files\Geant4\data），注意是解压方式是“解压到当前位置”

cmake编译，打开cmake-gui，配置cmake

  • 勾选GEANT4_BUILD_MULTITHREADED、GEANT4_USE_OPENGL和WIN32_GEANT4_USE_QT

  • 选择Add Entry添加一个编译选项CMAKE_PREFIX_PATH=C:\Qt\5.15.2\msvc2019_64

  • 将CMAKE_CONFIGURATION_TYPES设置为Release

  • 将GEANT4_INSTALL_DATA设置为C:\Program Files\Geant4\data

  • 选择Configure，选择Generate

  • 指定生成器为VS2019，生成器平台为x64

  • 如果需要启用 GDML，同时添加或勾选：GEANT4_USE_GDML=ON

  • 如果 Xerces-C++ 安装在自定义目录，例如 C:\dev\xerces-c，再把 CMAKE_PREFIX_PATH 改成包含 Qt 和 Xerces-C++ 两个路径：

使用管理员身份打开visual studio2019，编译安装Geant4

配置多核编译

1.在解决方案资源管理器中多选G4开头的目标项目并右键，选择属性 (Properties)。
2.进入C/C++→常规 (General)，将多处理器编译（Multi-processor Compilation）设置为是(/MP)。
3.在C/C++→代码生成 (Code Generation)中，将启用最小重新生成（Enable Minimal Rebuild）设置为否(/Gm-)。
4.菜单栏选择工具→选项 (Options)，展开项目和解决方案→生成与运行 (Build and Run)，将最大并行项目生成数设置为不超过CPU核心数。

ALL_BUILD生成

在解决方案资源管理器中右键ALL_BUILD，选择生成。

INSTALL生成

在解决方案资源管理器中右键INSTALL，选择生成。

修改当前配置为Release

  • 在页面顶部工具栏的 配置 下拉菜单中，可以看到当前已有的配置（如 Debug或Release），选择即可切换配置。
  • 若下拉菜单中没有Release配置，选择下拉菜单中的配置管理器选项，在打开的"CMake设置"对话框中，点击配置名称栏顶部的 加号 按钮。
    • 在弹出的对话框中：
    • 名称：输入 Release
    • 配置类型：选择 Release
    • 工具集：选择 msvc_x64_x64
    • 点击 确定 或 添加 完成创建。
    • 保存并重新生成：添加完成后，点击页面右上角的 “保存并重新生成 CMake 缓存” 按钮，VS 会重新运行 CMake 生成 Release 配置。
